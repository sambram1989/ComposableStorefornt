What’s a Referral Code?
A Referral Code is a unique code given to your patients that allows us to connect them to you. We do this by associating your unique code and your last name together.
To create a new Referral Code, type in the code you’d like, your last name, and the discount you’d like associated with that code (optional). You can review and edit the discount later in your dispensary settings page.
